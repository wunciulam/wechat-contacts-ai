保单页抓包

上次脚本报「没找到 erp_token」——因为这个保单页用的是另一套系统，凭证不在我以为的地方。这一步只做诊断，不改任何数据。

1
留在这个保单列表页
不用刷新、不用切换页面。就是现在这个能看到 待处理 / 投保单 / 保单 的页面。
2
复制脚本，粘到控制台回车
就是你现在这个已经开着的 Console。如果提示不允许粘贴，先输入 allow pasting 回车。
点一下即可
按钮没反应？点下面文本框全选，再按 ⌘+C：
3
点一张卡片的「电子保单」按钮
随便哪一张都行，会弹一个新标签页，不用管它，让它开着就好（看完可以关）。 这一下就能让脚本抓到真正的接口和凭证。
抓完之后，再点一下顶部「保单」标签，或者往下滚一屏 —— 这样脚本也能把「取保单列表」的接口一起抓到。
然后把控制台截图发我
  • 输出里会有一张 凭证表（来源 / 键名 / 长度 / 值前缀）
  • 一组 ▲ GET https://… 这样的请求记录，带请求头和响应片段
  • 一段 「电子保单」按钮的 HTML 绑定方式
关于隐私：脚本会把超过 40 位的长字符串自动遮成 <T176> 这种形式， 所以你截图外发不会泄露 token 本身。我要看的只是键名、路径和字段名。
