电子保单批量下载

全程 4 步 · 不用 token、不用装软件，最后得到一个含全部 PDF 的压缩包

1
打开「保单」列表页
就是有 待处理 / 投保单 / 保单 三个标签、每张卡片上有「电子保单」按钮的那个页面。 保持登录状态，能看到保单列表就行。
2
打开控制台
按 F12，或 Mac 上按 ⌥+⌘+I，点顶部 Console（控制台）标签。
第一次粘贴会被拦：控制台会提示 Warning: Don't paste code…。 先手动输入 allow pasting 回车，之后就能正常粘贴了。

4
粘贴到控制台，回车
粘贴后按 Enter。如果脚本没自动开始，就点一下「保单」标签或翻一页，它一捕获到数据就会自己跑起来。
它自己会做的事全自动
  • 从当前页面读登录凭证（erp_token），不需要你复制任何 token
  • 监听页面真实发出的列表请求，自动认出「取保单列表」的那个接口
  • 自动往下翻页，把所有保单 ID 抓全
  • 逐个调接口下载 PDF（3 个并发）
  • 打包成 一个 zip 下载 —— 不会被浏览器「多文件下载」拦截
  • 文件名尽量用「投保人_保单号.pdf」；重跑会自动跳过已下载的
为什么要打包：如果逐个文件下载，Chrome 下到第二个就会弹「是否允许下载多个文件」，很烦。 打包成一个 zip 只要下 1 次。

常见问题
  • 15 秒没反应 → 当前页不对。确认是保单列表页，然后点一下「保单」标签或翻一页。
  • 全部报「返回空内容」 → 登录态过期了。刷新页面重新登录，重进保单列表，再跑一次。
  • 只下了几份就停 → 浏览器拦了下载。点地址栏右侧图标允许，重跑会自动跳过已下的。
  • 想重新全量下载 → 控制台执行 myPolicy.reset() 再跑。
  • 想看抓到多少 → 控制台执行 myPolicy.report()，会打印保单清单表格。
  • 想立刻开始不等 → 控制台执行 myPolicy.start()。
  • 某个保司没有电子保单 → 控制台会打印该保司的原始链接，那个只能手动点。
