# 明亚保单导出

这是 Chrome / Edge 浏览器扩展。安装一次，以后登录明亚工作台即可反复采集。日常使用不调用 AI、不消耗模型 token，也不需要运行终端或粘贴代码。

## 安装一次

1. 将 `mingya-export-extension` 文件夹放在一个固定位置，不要删除或移动。
2. Chrome 地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」，选择此文件夹。
4. 在浏览器的扩展菜单里固定「明亚保单导出」。刷新已经打开的明亚工作台。

## 每次使用

1. 正常登录明亚工作台，进入顶部「保单」，再点内页的「保单」标签。
2. 点浏览器工具栏的「明亚保单导出」，选择范围，点「开始采集」。
3. 等待完成，点「导入跟单仔」，在跟单仔中预览合并结果，核对归属后确认导入。需要表格或备份时，也可点「导出 Excel」和「导出原始 JSON」。

「全部保单」取消列表筛选，并包含账号可访问的终止及托管保单。「当前筛选」保留当前保单列表的条件，并读取该条件下的所有分页。两种范围均根据网站返回总数核对，随后逐份读取详情。

可以关闭插件弹窗，采集仍在网页里继续；重新打开弹窗查看进度。请保持明亚网页打开，刷新或关闭网页会清空本次数据。中途停止可以导出已采集部分；再次采集会从头开始。

## 导出内容

- **保单汇总**：保单号、产品、保险公司、保费、币种、生效日期、保障结束日期、投保人、被保人、受益人、下次缴费日期、销售与服务人员等。
- **人员信息**：投保人、全部被保人、受益人的网站原始字段，每人单独一行。
- **险种信息**：主险与附加险的原始字段，每项一行。
- **全部字段**：列表和详情所有嵌套字段，包含条款、责任、险种要素、银行、备注等实际返回内容。使用字段路径区分层级，长文本分段保存。
- **采集结果 / 失败清单**：记录范围、总数、成功数和未取得的详情；有缺失时文件名会标注「部分」。

JSON 保留列表和详情的完整嵌套结构，适合备份或后续导入适配。登录凭证不写入导出文件。手机号、证件号等仍以网站实际返回为准；不恢复网站未提供或已脱敏的内容。原始状态、来源和单位代码保留为代码，插件不猜测含义、不换算币种。汇总中的超长文本节选展示，完整内容保存在「全部字段」和 JSON。

本版采集保单数据，不解析 PDF 文件内部文字，不批量下载电子保单或影像附件，也不采集「待处理」和「投保单」两个独立标签的数据。相关链接若由保单接口返回，会保留在原始字段中。

## 常见情况

- **提示进入保单列表**：首次安装后刷新工作台，依次点击顶部与内页「保单」。
- **登录失效**：重新登录、回到保单列表后重新采集。
- **数量变化或缺页**：保持账号和筛选条件稳定，重新采集；插件不会将缺页结果标为完整。
- **部分详情失败**：先导出保留已取得数据，查看失败清单；重新采集可重试。
- **清空**：停止采集后，在插件「使用说明」里点「清空本次数据」。

## 运行方式

权限仅用于明亚工作台与保单页面。复用页面自己的请求头和登录状态，只调用已核实的 `pageList` 与 `policyInfo` 两个读取接口；不操作网站的保存、隐藏、续期处理等功能。采集阶段保单和会话凭证仅暂存在当前保单网页内存，不保存到扩展的磁盘存储。选择「导入跟单仔」会将保单数据传给正式站预览；确认合并后，客户、保单、原始采集和导入前备份保存到跟单仔现有云端数据空间。登录凭证不传给跟单仔。Excel 库已随包提供，无须从网络加载。

基于 Chrome Manifest V3，参考：[Chrome 官方内容脚本文档](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)。

## 导入规则

按投保人归属。优先根据证件号、已确认保单关系或姓名与手机号共同匹配；同名需要选择。保险公司、保单号和生效日期共同去重，保留不同年度续保。默认仅补空缺，可在预览中选择用明亚更新保单字段；客户微信备注、标签、跟进记录保留。正式站已支持直连导入。手动导入入口：添加 / 导入 → 保单与缴费导入 → 明亚采集文件。
