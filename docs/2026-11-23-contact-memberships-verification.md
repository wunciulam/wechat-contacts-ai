# 联系人唯一、多分类关联

同名联系人（忽略空白、大小写，以备注名优先、昵称兜底）只保留一条，分类使用categoryIds关联；兼容旧categoryId。数据库触发器拒绝所有写入路径重复姓名，旧浏览器快照也不能重新插入重复记录。明亚导入同名归属必须确认合并，不能选择另建同名客户；手工录入、改名与跟进快捷创建也受约束。

分类变更通过单联系人事务保存，添加按姓名复用已有ID；重试不重复加入。拖动只移除来源关联、添加目标，移出只影响当前分类。最后一个分类移除才退出跟进。列表计数按人去重，每列独立计数；拖动ID包含分类，避免同一联系人多列出现时冲突。页面内分类请求串行提交，避免返回顺序覆盖界面。

正式数据：在事务回滚试运行验证跟进内容、保单ID均保留后，备份并合并两组同名记录。当前162位联系人、62条跟进。“郭子豪”的两个分类合并到同一ID；“吴琛”五条跟进保留。数据库contact_merge_backup:前缀存完整合并前客户、续期和ID映射；合并后的联系人也保留原资料快照。保单归属ID在客户与续期视图同步映射，不修改缴费记录。

验证：47项测试、网页类型检查和构建通过。数据库匿名角色事务回滚断言覆盖按姓名复用、重复添加、跨分类移动、单列移出、末列移出、记录/标签/保单保留、拒绝重复名字及失效分类。1304×880浏览器验证两列同人、第三列添加、失败重试、单列移出、真实鼠标拖动、共享资料打开和刷新；390×844验证标题/设置单行、工作台容器横向滚动且整页不溢出。界面测试使用虚拟数据。
