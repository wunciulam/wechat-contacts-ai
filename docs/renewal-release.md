# 续费与明亚导入分支

基线：4e3a2a8 + 生产保单弹窗修复 43d218b。
分支：codex/policy-renewal-import；独立工作目录，不修改旧工作区。

## 当前实现

- 续费待办入口、右上角提醒设置、三类明亚 Excel 解析与确认导入。
- 保单公司+保单号去重，期次按应缴日期合并；同一期最新表格覆盖人工状态并保留记录。
- 姓名结合手机/证件尾号关联；同名但不足以确认的需手动核对。
- 投保/被保关联查询，从原客户弹窗进入；保单和联系人通过单次 upsert 原子提交。
- 提前30天，逾期保留，每保单最新未缴期次；明确到期日支持续保标记。
- 邮件接口使用 QQ SMTP SSL，凭据只在服务端；每天唯一发送记录，未配置时无法开启。

## 邮件尚需配置

Production 环境变量：SMTP_USER（发信QQ邮箱）、SMTP_PASSWORD（QQ邮箱SMTP授权码）、CRON_SECRET（随机调用密钥）。不得使用 VITE_ 前缀存放发信凭据。
需配置 Supabase Cron 每分钟请求 /api/renewal-email（POST，Bearer CRON_SECRET）；服务端按北京时间设置判定并按日期防重。
调度验证完成后设置 RENEWAL_SCHEDULER_READY=true，再允许界面开启发送。
