# 跟进历史与导入批注验收

分支：codex/pen-followup-workbench。仅本地实现，未发布、未切换正式域名。

## 行为

- 所有沟通历史支持编辑日期、渠道、内容及删除。保留原话文字；改日期时原话一起归档。删除同时删除附属原话，关联待办完成状态不变。复用原有RPC、冲突校验及删除墓碑，历史变更使旧AI分析待更新。
- 历史上下内边距8/10px，渠道间隔4px。年度标题#0f0f0f/600，作用于所有响应尺寸，不改变全局辅助文字。
- 工作台和详情不再显示逾期天数。用户确认：未完成且早于上海时区今天才红，今天和未来正常。
- 截图点击打开共享弹窗，可适应宽度、原始大小、缩放、拖动平移。关闭不丢导入草稿，不重跑识别，图片仅临时内存使用。
- 鼠标框选保留/取消，按气泡命中，边缘自动滚动，拖动不误打开编辑。手机继续勾选，不抢滚动。
- 未逐条核对也可生成梗概。只处理已选且日期、角色明确的消息；缺失者提示数量并暂不处理。待核对标记随原话归档，不猜日期，不补写不清楚的内容。
