# 自动保存、复选组件与原话弹窗

分支codex/pen-followup-workbench。本轮用户要求直接修改，未更新Pen或发布。

## 功能

- 详情资料页使用600ms防抖自动保存；请求串行，新输入在前次完成后继续提交。失败保留草稿，重试或更改后再提交。切换页签、关闭前等待分类创建并flush，失败停留原页；刷新时有未保存内容则触发浏览器离开保护。新建客户表单仍保留创建确认，避免自动创建半成品。
- 自动保存仅允许资料字段进入服务端最新快照，保护并发历史、保单、分析和跟进状态。沿用既有资料RPC及字段冲突校验，无数据库迁移。
- 客户分类改为公共TokenInput输入、选择、移除，新增名称先保存分类配置再关联客户。移除关联不全局删除分类；失败可重试。
- 侧栏两组筛选全选及条目均复用公共Checkbox，部分选中为indeterminate，支持键盘Space。保留跨组交集逻辑。
- 公共Tag增加居中约束，取消被输入容器拉高。
- 跟进原话改共享弹窗，日期在标题栏，保留完整内容、换行与待核对标记，正文滚动，Escape返回客户详情。
- AI动效32秒加快为16秒；prefers-reduced-motion下仍静止。
- 改期与删除均为18px图标、桌面32px按钮。日期末尾不预留操作宽度，悬停/聚焦时覆盖。无hover设备下方44px操作区，避免常驻按钮遮挡日期；工作台窄屏最后一列用max-content。
