# 全局提示、分类删除与发布验收

## 提示归集清单

|来源|原提示|处理|
|---|---|---|
|客户详情|记录已更新/删除、结果已保存、待办已完成、撤销完成|全局通知，撤销动作保留|
|工作台|当前线索已是最新、结果已保存到跟进历史、已恢复待办|全局通知|
|资料|自动保存成功、旧跟进录入成功/加入草稿|全局通知|
|保单|保单资料已保存|全局通知|
|AI设置|连接成功、已保存并启用|全局通知|
|旧表格导入|新增/更新联系人及新增保单数量|由alert改全局通知|
|状态/校验|保存中、字段错误、识别进度、明亚导入详细结果|属于任务状态或可操作错误，保留原处|

全局通知最多3条，同ID或同消息合并。普通4秒/错误7秒/带撤销12秒；操作中暂停计时，失败保留重试。通知根据最上层原生dialog迁移挂载点，固定在视口右上，既不会被遮挡，也不挤占业务内容。无窗口刷新，不移动字段验证信息。
