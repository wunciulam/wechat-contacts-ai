# 聊天跟进本地预览

分支 `codex/chat-followup-ocr` 基于正式版提交 `d8fe13c`。运行 `npm run dev` 后访问 `http://127.0.0.1:4179/`。开发服务绑定本机，使用独立示例客户和本地数据文件。线上数据库、分支和域名未改动。

从「跟进工作台」或客户详情的「跟进历史」打开「导入聊天」。浏览器识别首批截图。调整图片顺序后可重新识别。可以校对原文、补充线下沟通、只存文字或分析下一步。待办和原文随同一条跟进保存。

## 验证

- Chrome 合成中文截图覆盖批量识别、重叠去重、说话人归属和长图切分。测试素材使用虚拟对话。
- 浏览器测试覆盖分析失败、原话依据、待办日期、保存失败并重试、刷新后查看原文、完成待办及仅存线下备注。
- 本地预览另行验证浏览器 OCR、数据写入本地文件和刷新回读。没有外部 OCR 请求。
- DeepSeek 用模拟响应验证前端流程。缺少 Key 时已验证可以继续归档。真实 API 的连通性和建议质量留待本地设置 `DEEPSEEK_API_KEY` 后验证。
- 检查了 1304 × 880 桌面截图、390 × 844 手机截图、下拉展开、正文滚动、固定保存栏、Escape 和保存失败状态。证据在 `output/ui-regression/`。

## 界面文案

删掉了客户下拉里重复的「选择客户」。如果线下原句已经作为摘要展示，历史中省去重复的展开区。保留识别缺漏、说话人待核对和失败反馈，方便纠正原话并继续操作。原文与分析依据默认折叠。

OCR 校对仍有必要，尤其在非标准截图布局或图像不清晰时。正式接入前需要单独验证共享环境中的客户数据访问权限。
