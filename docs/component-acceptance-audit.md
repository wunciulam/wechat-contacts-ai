# 组件验收样板：现状盘点与待确认选择

本文件是 2026-10-23 对本地运行网页的观察和验收说明，**不是最终 `design.md`**。样板页面为 [`/ui-acceptance.html`](../ui-acceptance.html)，使用独立 React 入口和虚构数据，不调用客户或保单服务。未获确认前，不据此改造现有业务页面。

## 其他模块验收页

[`/module-acceptance.html`](../module-acceptance.html) 继续提供三个实际模块的本地示例：联系人卡片/列表切换、搜索、空状态和批量栏；跟进工作台列、空列、长卡片与跨列移动；保单管理客户折叠、表格、详情、续期提醒、通知设置与导入预览。所有保存和状态变更只在当前页面内模拟，刷新即复原，不接入数据库或邮件服务。这些仍是待确认的界面样板，并非业务功能验收。

## 给验收者：怎么反馈

直接在本地验收页选中不满意的控件并留言，说明希望改成什么样即可；不用逐行阅读或填写下面的盘点表。下面的开放项用于我们核对差异，并非要求逐项投票。每条页面标注都会落实到验收页，再由你检查。只有你明确说“样板确认”，才定稿 `design.md` 和修改业务页面；正式版发布仍暂停。

## 参照页面

优先参照「全部联系人」的页面标题、白底网格与浅灰边框，以及「新增联系人 → 手动录入」的遮罩、标题栏、表单和底部按钮。它们在桌面和手机上都有相对完整的结构。「保单管理」展开后的表格提供业务字段和行结构，但它的字号、列宽和缺失值呈现本身仍需要检查，不能整页照搬。「续期提醒」只作为差异对照，不作为视觉基准。此次选择依据是运行网页和当前代码，不采用此前 Pen 画板作为标准。

## 状态与交互覆盖

- 色板：原站的中性灰沿用 `index.css` 中 50–900 的十档；亮蓝、翠绿、明琥珀、亮紫、珊瑚红也各展示 50–900 十档，均为待确认候选。页面白色为 `#ffffff`。本地样板仅用中性灰组织页面、主按钮和边框；辅助色的 100/700 档分别用于标签底/字，珊瑚红 500 用于错误输入框边框、700 用于错误文字和必填星号。旧样板里鲜红的提示已改为同一珊瑚红色系，页面不再混用未列出的错误色。
- 字号：字族沿用 `index.css` 的 Inter / PingFang SC / Microsoft YaHei；页面标题 18px、区块/弹窗标题 16px、正文/按钮 14px、表头/辅助文字 12px，标题/正文/按钮标签的字重候选分别为 600/400/500。字号来自现有 `PageHeader`、`.input`、联系人卡片和弹窗的组合，过小的 9–10px 内容是建议修正项。
- 间距与尺寸：以 4px 为单位展示 4/8/12/16/20/24px；按钮 36px、输入框 38px、圆角 4/6/8/12px 的候选用途取自当前 `index.css`。此页展示候选，尚未修改全站样式变量。
- 标题：正常计数、说明、手机动作换行。
- 按钮：主次、长文案、弱动作、禁用。
- 输入：正常、长值、空值、错误、禁用、下拉；搜索图标与文字留有明确间距。
- 数字：金额等可带小数的数值统一两位小数，显示千分位；零值显示 `0.00`，缺失显示「待补充」。日期、保单号、期数和剩余天数按各自业务格式显示，不加小数。
- Tab：正常、长标题、空内容、禁用项；可点击和用方向键切换，手机只在 Tab 区域内横向滑动。另展示列表筛选的分段按钮。
- 标签：普通、长文案、空值、需核对；错误也采用填充标签，不另造描边形状。表格中的剩余天数也使用标签。
- 客户卡片：正常、长姓名与备注、无标签记录、资料待核对。
- 客户卡片右上角只显示“跟进中”，前置亮蓝 500 的小圆点；暂未跟进和需核对不在右上角重复显示，待核对信息仍由标签与说明表达。
- 保单表格：正常、长产品名、缺失日期/金额/期数、空表；详情按钮打开样板弹窗。
- 弹窗：可打开、只滚动正文、空名称报错、填值后本地保存反馈、取消、关闭、Esc。

## 验证记录

- 网页端 TypeScript 检查：`npx tsc -p tsconfig.web.json --noEmit` 通过。
- Vite 构建通过，含独立的 `ui-acceptance.html` 入口。
- 运行截图尺寸：桌面 1304×880、用户标注时的 968×880、手机 390×844。手机验收页文档宽度为 390px；Tab 区域内容宽 374px、可视宽 358px，局部可滑动而页面没有水平溢出。表格仍仅在自身区域横向滚动。
- 按用户在验收页标注修正：搜索输入文字不再与图标重叠；错误标签与普通标签统一为填充样式；表格剩余天数使用标签。Tab 的点击、方向键、空内容与禁用状态已在运行页面检查。
- 第二轮标注：下拉改为站内样式和固定箭头留白；弹窗必填星号与其他错误提示统一使用珊瑚红 700；每个色系展示十档并限制用途；样板金额统一两位小数。以上仍仅在验收页生效。
- 色板继续待确认：按用户反馈整体提亮五组辅助色的 50–900 十档，中性灰、布局和主按钮不变；标签、状态圆点和错误提示同步引用新的色板档位。
- 下拉经运行页面检查：可展开年缴/月缴/季缴，方向键和回车可选择，选中后菜单关闭；金额列显示 `¥ 2,400.00`、`¥ 12,000.00` 和「待补充」。此轮按用户偏好不重复截屏验证，保留先前对照页供需要时查看。
- 弹窗实测：空名称报错；输入后出现本地保存反馈；长内容正文可滚动；Esc 可关闭。截图见 `output/playwright/`。
- 仓库的原 `npm run lint` 涵盖未安装依赖的小程序工程，会报 Vue/Pinia 及小程序类型错误；网页端专用检查已通过。该问题与此验收页无关。
