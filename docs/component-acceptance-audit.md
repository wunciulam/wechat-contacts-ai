# 组件验收样板：现状盘点与待确认选择

本文件是 2026-10-23 对本地运行网页的观察和验收说明，**不是最终 `design.md`**。样板页面为 [`/ui-acceptance.html`](../ui-acceptance.html)，使用独立 React 入口和虚构数据，不调用客户或保单服务。未获确认前，不据此改造现有业务页面。

## 参照页面

优先参照「全部联系人」的页面标题、白底网格与浅灰边框，以及「新增联系人 → 手动录入」的遮罩、标题栏、表单和底部按钮。它们在桌面和手机上都有相对完整的结构。「保单管理」展开后的表格提供业务字段和行结构，但它的字号、列宽和缺失值呈现本身仍需要检查，不能整页照搬。「续期提醒」只作为差异对照，不作为视觉基准。此次选择依据是运行网页和当前代码，不采用此前 Pen 画板作为标准。

## 状态与交互覆盖

- 标题：正常计数、说明、手机动作换行。
- 按钮：主次、长文案、弱动作、禁用。
- 输入：正常、长值、空值、错误、禁用、下拉。
- 标签：普通、长文案、空值、需核对。
- 客户卡片：正常、长姓名与备注、无标签记录、资料待核对。
- 保单表格：正常、长产品名、缺失日期/金额/期数、空表；详情按钮打开样板弹窗。
- 弹窗：可打开、只滚动正文、空名称报错、填值后本地保存反馈、取消、关闭、Esc。

## 验证记录

- 网页端 TypeScript 检查：`npx tsc -p tsconfig.web.json --noEmit` 通过。
- Vite 构建通过，含独立的 `ui-acceptance.html` 入口。
- 运行截图尺寸：桌面 1304×880、手机 390×844。手机验收页文档宽度为 390px，表格本身宽度 1020px 且其外层容器宽度 356px，页面没有水平溢出。
- 弹窗实测：空名称报错；输入后出现本地保存反馈；长内容正文可滚动；Esc 可关闭。截图见 `output/playwright/`。
- 仓库的原 `npm run lint` 涵盖未安装依赖的小程序工程，会报 Vue/Pinia 及小程序类型错误；网页端专用检查已通过。该问题与此验收页无关。
