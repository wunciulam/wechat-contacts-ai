# 保单导入过滤、批量删除与列宽

范围：终止、最终撤单在导入前过滤；已存在的记录不自动删除。中止、撤单中不视为最终状态。明亚保单列表前端的状态选项核实为16正式、17终止、18中止、21撤单中、22已撤单。JSON及工作簿使用同一规则。

批量删除按客户与保单ID校验，在同一事务更新续期及所有关联客户保单副本，保存所选保单/缴费备份。请求ID支持失败重试。客户、跟进、备注及设置不删除。数据库断言覆盖无效归属整批拒绝、跨客户副本、仅手动保单、备份及重复请求，测试事务全部回滚。

验证：43项测试通过，网页类型检查、构建通过。1304×880浏览器验证全选、半选、取消、失败保留、同请求重试、刷新后保单保持删除，原有跟进不变。鼠标拖动操作列128→228px，刷新保持；水平滚动时操作列固定。390×844限制操作列最大160px，无整页水平溢出，删除确认操作可见。界面测试使用路由替代数据库，未删除真实保单。

文案独立走查：批量工具条仅在勾选后显示数量及两个动作，不增加常驻操作说明；删除后不另堆叠同义成功提示。确认页保留产品名、单号和一次删除范围说明，用于核对对象及影响。导入只新增一行过滤计数，逐单原因在折叠明细中查看。桌面、手机及水平滚动状态截图保存在output目录。
